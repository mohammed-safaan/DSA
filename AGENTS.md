# AGENTS.md

## Repo purpose

Personal journal of a data-structures-and-algorithms learning journey. Solutions to problems from NeetCode, LeetCode and HackerRank, written in C (for fundamentals) and JavaScript (primary submission language). This repo is a public-facing portfolio — everything committed here is visible to recruiters. Keep it clean, professional, and honest.

## Agent skills

### Issue tracker

Learning tasks and PRDs live as local markdown files under `.scratch/` in this repo. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical states: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` at the repo root plus `docs/adr/` for learning decisions. See `docs/agents/domain.md`.
