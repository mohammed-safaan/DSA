# Data Structures & Algorithms — Learning Journey

A public journal of my systematic practice in data structures, algorithms and problem solving. Every folder is a record of real practice: the problem, the approach, the complexity, and what I learned from it.

**Languages:** C (fundamentals) · JavaScript (primary submissions)
**Platforms:** [NeetCode](https://neetcode.io/) · [LeetCode](https://leetcode.com/) · [HackerRank](https://www.hackerrank.com/)

## Why this repo exists

I am working through data structures and algorithms the way they're actually asked in interviews: pattern by pattern, not problem by problem. This repo shows that journey as it happens — honest problem counts, verified links, and written reflections.

Each problem folder contains:

- **The solution** in C and/or JavaScript, formatted and tested.
- **A solution note** (`README.md`) with the problem link, the approach in my own words, time/space complexity, and a short reflection — where I got stuck and what I'd do differently.
